Dynamic Architecture & Backend Integration

How this Dashboard connects to a Live Backend

Currently, this panel works seamlessly with a client-side JSON store (`localStorage`), which immediately allows you to test, edit, add, and delete products, hero banners, categories, brands, and gallery photos. When you are ready to connect to a production database (PHP MySQL, Node.js Express, Python FastAPI, or Supabase/Firebase), use the schema and endpoints below.

Export Data to JSON

Download a full JSON backup of all 5 modules (Hero, Categories, Brands, Products, Gallery).

Import Data from JSON

Upload a JSON backup or seed file to populate the entire store catalog instantly.

Reset to Default Data

Restore factory default items (all 16 products, 8 categories, 8 brands, 2 hero banners).

Recommended Backend API Endpoints (Node.js / PHP / Python / Go)

// 1. Hero Sliders
GET /api/sliders // Get all active slides
POST /api/sliders // Add new slide
PUT /api/sliders/:id // Update slide
DELETE /api/sliders/:id // Remove slide
// 2. Categories
GET /api/categories // List categories
POST /api/categories // Create category
PUT /api/categories/:id // Update category
// 3. Brands
GET /api/brands // List brands
POST /api/brands // Add brand
// 4. Products
GET /api/products // Filter by brand, cat, q
POST /api/products // Create product
PUT /api/products/:id // Edit product
DELETE /api/products/:id // Delete product
// 5. Gallery & Inquiries
GET /api/gallery // Get showroom photos
POST /api/gallery // Upload photo
GET /api/orders // Quotation records
